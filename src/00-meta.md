Это практический курс по **Docker**: ты не обязана знать, что такое контейнер, а к последней сессии собираешь, оптимизируешь и публикуешь свой стек и объясняешь каждую строку в нём.

**Как устроена лаба.** 12 сессий по 3–4 часа. В каждой 6–7 шагов, и у каждого шага один ритм: **слова шага → команда по частям → ожидаемый результат → вопросы «Проверь себя»**. Один шаг в каждой сессии — **🔨 «сломать → починить»**: мы нарочно делаем типичную ошибку и учимся читать сообщение. Блоки «Под капотом», «Как ещё можно» и «Если не получилось» можно открывать по необходимости.

**Сквозной проект CoffeeShop** — маленькая кофейня в интернете: API на Node.js (меню и заказы), статический сайт на nginx, база PostgreSQL и Adminer для просмотра базы. Он начинается с одного контейнера и к концу превращается в стек, который поднимается одной командой на чистой машине. Тот же стек потом едет в Traefik, Kubernetes и Ansible.

**Среда.** Docker Desktop на Mac (шаг 1.3 объясняет, что внутри и чем его заменить). Все команды выполняются в обычном терминале Mac; других лаб проходить не нужно, Bash желателен, но не обязателен — всё нужное объясняется по ходу.

**Что в конце.** Сессия 11 — итоговый стек и Production Hell без подсказок, сессия 12 — самостоятельное техническое задание без готового решения. Публикация в GitHub Container Registry и GitHub Actions (сессия 10) нужны твоим личным токеном и аккаунтом: эти шаги расписаны подробно, но выполняются самостоятельно, и в методичке они помечены.

Версии: Docker Engine 29, Compose v5, BuildKit через buildx 0.34, PostgreSQL 18, Node 24, nginx 1.30. Все примеры выполнены настоящим запуском в изолированном Docker, а выводы в блоках «Ожидаемый результат» получены оттуда же (идентификаторы, даты, размеры и порядок строк у тебя будут другие). Исключение — `docker version` и `docker info` в шаге 1.3: они сняты с настоящего Mac.
